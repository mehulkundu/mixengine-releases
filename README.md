# Mix Engine — releases

Installers and the in-app update feed for **Mix Engine**, the desktop app for
DJ set preparation. Download it from **[getmixengine.com](https://getmixengine.com)**.

This repository holds release files only — there is no source code here, and
none of it is open source. Builds are produced by the private development
repository's release pipeline and uploaded here on every tagged version.

| Platform              | File                                 |
| --------------------- | ------------------------------------ |
| macOS (Apple silicon) | `mix-engine-macos-aarch64.dmg`       |
| macOS (Intel)         | `mix-engine-macos-x64.dmg`           |
| Windows (installer)   | `mix-engine-windows-x64-setup.exe`   |
| Windows (MSI)         | `mix-engine-windows-x64.msi`         |
| Linux                 | `.AppImage`, `.deb`, `.rpm`          |

`latest.json` on the newest release is the update feed the app checks.
